Legacy — консольная версия (ППО LR5)

У исходного проекта не было MPA/SPA-интерфейса — рабочим интерфейсом был CLI (TUI). Здесь он доступен в виде сборки и работает через REST API.

Скачать

Скачать консольную версию (subscriber-cli, macOS arm64) — готовый бинарник, работает через REST API.

Сборка из исходников

cd cmd/cli
go build -o subscriber-cli .
./subscriber-cli --help

CLI обращается к API по адресу из переменной окружения API_URL (по умолчанию http://localhost:9090):

export API_URL=http://localhost:9090
./subscriber-cli get-services
./subscriber-cli get-plans
./subscriber-cli create-user --email demo@ex.com --name Demo

Доступные команды

users / services / plans / subscriptions / promocodes / analytics — порядка 20 команд чтения и записи.
